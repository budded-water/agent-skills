# Working rules

Keep skill scope narrow and read the relevant SKILL.md before editing it.
Preserve source attribution and permission boundaries in NOTICE.md.
Preserve the MIT license and inherited contribution attribution when redistributing.
Use topic branches and PRs; a passing check does not authorize merging.
Run pytest and shell syntax validation for changes to executable behavior.
Do not alter user installations, hooks, MCP, credentials or permissions as a
side effect of repository tests. Use temporary targets and fake provider responses.
Keep provenance, README, migration instructions and installer behavior consistent.
